# Proxemics of Physical AI: UIST 2026 Workshop

Website: https://praneethperera99.github.io/proxemics-of-physical-ai/

Static single-page site. No build step.

| Path | Contents |
|---|---|
| `index.html` | All page content |
| `assets/css/style.css` | Styles (colors and fonts at the top) |
| `assets/img/` | Teaser, social preview image, keynote and organizer photos |
| `assets/fonts/` | Space Grotesk and IBM Plex Sans (SIL Open Font License) |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

## Branches

- `main`: published by GitHub Pages
- `dev`: work in progress

Edit on `dev`, then merge into `main` to publish.

## Preview

Open `index.html` in a browser.
